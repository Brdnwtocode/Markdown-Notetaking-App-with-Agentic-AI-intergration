# C3-01 — Feature Overview

## The One Big Idea
Lock In is not five separate apps stitched together. It is one unified workspace with five integrated modules — Notes, Stacks, Tasks, Calendar, and Records — all wrapped around a shared AI layer that understands and acts across every module.

## Visual Concept
A hub-and-spoke diagram. The center hub is "Lock In Workspace" with an AI brain icon. Five spokes radiate outward to module nodes, each with its icon, name, and a one-line capability description. A ring around the outside represents the AI layer (Agentic Automate + AI Companion) wrapping all modules. Clean, spacious, scannable.

## Content Elements

### Headline
Five Modules. One AI Brain.

### Hub (center)
**Lock In** — Unified personal knowledge workspace

### Five Spokes

| Module | Icon | What It Does |
|---|---|---|
| **Notes** | Document | WYSIWYG Markdown editor — write, format, organize. Live preview, autosave, image upload. |
| **Stacks** | Table grid | Dynamic typed tables — Text, Int, Float, Boolean, Date, Select. JSONB storage means no schema migrations. |
| **Tasks** | Checklist | Hierarchical task management — parent-child subtask trees, status tracking, priority levels. |
| **Calendar** | Calendar | Event scheduling with color coding — week and month views. |
| **Records** | Microphone | Audio workstation — background recording, real-time STT streaming, playback controls, AI extraction. |

### AI Ring (encircling all modules)
**Agentic Automate** — voice-to-action pipeline. **AI Companion** — context-aware conversational assistant. Both work across all five modules.

## Interactive Notes
