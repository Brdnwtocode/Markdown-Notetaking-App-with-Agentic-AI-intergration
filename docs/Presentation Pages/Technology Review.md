The Lock In system is a full-stack, web-based workspace. Every technological choice in this stack was driven by a central requirement: delivering a fluid, responsive user experience where AI acts as a reliable, controlled partner rather than an unpredictable black box.
Next.js 14 + Zustand (The User Experience & Trust Layer)
The Technology: The frontend is powered by Next.js 14 (App Router) for server-side rendering, paired with Zustand for client-side state management across ten modular slices. The UI utilizes Tailwind CSS with custom-built components, rendering a dark-mode workspace with an emerald (#10B981) accent system.
User & Business Impact: In AI-integrated workspaces, the primary user problem is trust — users fear AI will overwrite or corrupt their data. To solve this, Zustand manages a strict staged-mutation model. When the AI proposes a change — inserting text into a note, adding a row to a table, creating a task, or scheduling a calendar event — the UI renders an inline text diff or a highlighted "ghost row." The database is never mutated until the user explicitly clicks "Accept." This human-in-the-loop design guarantees that the user maintains absolute control over their knowledge base. The system covers nine mutation types (note updates, single and bulk stack row operations, task management, calendar events, bundled automate results, and summaries), each with built-in rollback logic and undo history.
Neon PostgreSQL + Prisma ORM + S3 Object Storage (The Data & Persistence Layer)
The Technology: Neon provides a serverless PostgreSQL infrastructure, accessed via Prisma ORM for type-safe queries. An abstracted S3-compatible storage layer (AWS SDK) handles audio file persistence, adapting between MinIO (local development) and AWS S3 or Cloudflare R2 (production) via environment variables.
User & Business Impact: Users need to manage both unstructured thoughts (Notes) and highly structured tracking (Stacks/Tables) without learning database management. By utilizing Postgres JSONB for Stack rows, the system allows end-users to dynamically create custom columns (Text, Int, Float, Boolean, Date, Select) on the fly — without schema migrations. The schema also supports self-referential hierarchical models for both folders (nested organization) and tasks (parent-child subtask trees). For the Records Workstation, audio files that can reach hundreds of megabytes are offloaded to S3 object storage — cleanly separating structured metadata (Postgres) from binary media (S3), with presigned URLs enabling direct browser-to-storage uploads and streaming playback.
FastAPI + LangGraph + Pydantic (The Agentic AI Engine)
The Technology: A dedicated Python microservice built with FastAPI isolates all AI processing from the web frontend. The Next.js backend acts as a Backend-For-Frontend (BFF) proxy — authenticating users, translating field conventions, and forwarding requests to FastAPI. The service orchestrates AI reasoning through a LangGraph StateGraph — a compiled, stateful directed graph — and uses Pydantic v2 for runtime schema validation.
User & Business Impact: The LangGraph architecture structures AI processing as a multi-node pipeline rather than a single monolithic LLM call. The Safety Gate validates transcripts against prompt injection attacks using delimiter-wrapped boundaries. The Complexity Router (regex-based, no LLM cost) determines whether a command is simple or complex. For complex queries, parallel expert nodes — Contrarian (risk assessment), Research (workspace grounding), and Conversation (intent extraction, language detection) — execute concurrently via LangGraph Send parallelization. The Planner decomposes multi-step commands, the Synthesizer combines expert outputs, and the Resolver generates a structured JSON action payload. A Reflection node evaluates output quality — looping back if the score falls below threshold (< 0.8). This ensures simple commands resolve in a fast single path, while complex queries receive multi-step deliberation. Pydantic's dynamic schema generation (via `create_model()`) eliminates data hallucination by mathematically constraining LLM output to match the user's actual Stack column types — voice commands are translated into schema-compliant data entries with zero manual formatting.
Deepgram Nova-3 + Context Packing (The Voice & Intelligence Layer)
The Technology: Real-time speech-to-text is powered by Deepgram Nova-3, streamed over a persistent WebSocket connection (linear16 PCM, 16kHz, Vietnamese language primary). Before any AI request is dispatched, a ContextPacker automatically resolves active workspace tabs, extracts their content (note text, stack schema and row data, task metadata), processes @mentions, and assembles a structured context payload.
User & Business Impact: Voice is the fastest natural input modality — conversational speech runs at 125–150 WPM versus 40–60 WPM for keyboard typing. For Vietnamese-speaking users using telex/VNI encoding, the speed advantage is even greater. WebSocket streaming provides near-instantaneous transcription — users see words appear as they speak, making voice interaction feel conversational. The system provides two modes: push-to-talk in the ChatSidebar (quick commands) and continuous recording in the Records Workstation (long-form capture with 60fps waveform visualization, background persistence, and S3 storage). Context packing solves the critical intelligence problem: without it, "add a row for today's meeting" is meaningless — the AI wouldn't know which table, what columns, or what types. By automatically injecting the active note content, current Stack schema, and focused task into every request, the AI understands user-defined data structures without hardcoded prompts.
Summary of Architectural Advantages
Separation of concerns via microservice architecture (Next.js for UI/session/persistence, FastAPI for AI reasoning/schema validation).
Modern, type-safe codebases (TypeScript + Python type hints + Pydantic runtime validation).
Graph-based AI orchestration (LangGraph StateGraph) enabling conditional routing, parallel execution, and self-correcting reflection loops.
Human-in-the-loop safety gate on every AI mutation (staged diff previews, ghost rows, accept/reject before database commit).
S3-compatible object storage for scalable audio file management with presigned URL workflows.
By decoupling the application into a React frontend, a Node.js BFF gateway, and a Python AI brain, the system abstracts complex schema validation and multi-node AI orchestration away from the user, presenting them with a simple, voice-driven interface that is fast, schema-aware, and inherently safe.
