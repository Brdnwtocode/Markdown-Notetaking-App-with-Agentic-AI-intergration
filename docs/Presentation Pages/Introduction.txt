RATIONALE FOR THE PROJECT


In recent years, the rapid growth of digital tools has significantly changed how students and young professionals manage information, learn, and work. Note-taking applications and knowledge management systems have become essential in organizing ideas, tracking tasks, and supporting long-term learning. However, despite their widespread adoption, most existing tools still present notable limitations in terms of interaction efficiency and integration with intelligent systems.
Current platforms such as markdown editors such as Obsidian-desktop app or all-in-one workspaces Notion-webapp provide either flexible note-taking or structured data management, but rarely offer a seamless combination of both. More importantly, although artificial intelligence has been increasingly integrated into these systems, it is often limited to passive assistance—such as generating text or answering questions—rather than actively executing user intentions within the application. As a result, users are still required to manually interpret AI outputs and perform corresponding actions, which interrupts workflow and reduces productivity.
Another key limitation lies in the lack of effective multimodal interaction, particularly voice-based control. While speech-to-text technologies exist, they are typically used only for transcription rather than enabling meaningful interaction with both unstructured content (notes) and structured data (tables). This creates a gap between natural user input and actual system operations.
To address these challenges, this project proposes the development of a multimodal note-taking system with integrated AI interaction. The system is designed as a lightweight “all-in-one workspace” that combines markdown-based note-taking, schema-defined structured data management (Stacks), and an AI voice assistant capable of understanding and executing user commands. By leveraging schema-aware AI through function calling, the system enables direct mapping from natural language input to concrete actions on user data.
The objective of this project is to reduce manual operations, streamline user workflows, and provide a more natural and efficient way for users to interact with their personal knowledge systems. Ultimately, it aims to demonstrate how multimodal AI interaction can enhance both usability and functionality in modern productivity applications.
OBJECTIVES OF THE PROJECT


Bridge the Paradigm Gap in Knowledge Management: Unify free-form ideation (unstructured Markdown) and rigid data tracking (structured relational tables) into a single, seamless workspace, thereby eliminating the cognitive penalty of context-switching between disparate apps.
Eliminate Manual Input Friction: Transform the user from a manual typist to an intent-driven operator. By integrating a voice-first agentic assistant, the system empowers users to execute complex workspace operations at the speed of thought.
Enforce Deterministic AI Reliability: Eradicate the risk of "AI hallucinations" in data entry. A primary goal is to engineer dynamic, runtime schema validations that mathematically force Large Language Models (LLMs) to output data perfectly compliant with user-defined database structures.
Achieve Conversational Responsiveness: Guarantee an ultra-low-latency processing pipeline (≤ 4 seconds end-to-end) so that voice interactions feel as immediate and fluid as human conversation, preventing workflow interruptions.
Ensure Absolute Data Sovereignty: Design a strict "Human-in-the-Loop" architectural safeguard. By utilizing cryptographic prompt injection defenses and mandatory UI confirmation gates, the goal is to guarantee that the AI acts only as a safe, suggestive copilot, never mutating the database without explicit user consent.
Deliver an Comprehensive, Extensible Architecture: Engineer a decoupled, stateless microservice foundation (Next.js frontend + FastAPI AI Brain) that supports multi-model AI routing, allowing the platform to easily absorb future advancements in AI technology

SCOPE OF THE PROJECT

Function scope
The project is designed for students and young professionals who require a more efficient and intuitive way to manage personal knowledge in a digital environment. The system focuses on providing a centralized, web-based workspace that supports both content creation and data organization within a unified platform.
The primary objective is to improve how users interact with their information and knowledge by reducing reliance on manual input and fragmented tools. Instead of separating note-taking, data tracking, and AI assistance into different applications, the system integrates these functionalities into a single environment. This allows users to perform tasks such as writing notes, organizing structured data, and updating content more efficiently.
The overall goal of the project is to create an intuitive and integrated knowledge workspace that enhances productivity and usability. By combining note-taking, structured data management, and multimodal AI interaction, the system aims to provide a more natural and efficient way for users to capture, process, and interact with information.
Research scope
The project has two primary research objectives: mastering the technical architecture required for a multimodal AI-driven knowledge management system and understanding the practical needs of users in managing and interacting with personal knowledge.
For the first objective (Technical): The emphasis is on researching modern web technologies and system design needed to build a responsive, real-time application that integrates both unstructured and structured data. This includes studying the implementation of a Markdown-based editor, dynamic table systems with schema definition, and state management for synchronized UI updates. In addition, the project requires in-depth exploration of multimodal AI integration, 
particularly Speech-to-Text (STT) and Large Language Models (LLMs) with function calling. Special attention is given to designing a pipeline that converts natural language input into structured actions, as well as handling API communication, latency optimization, and data consistency during AI-assisted operations.
For the second objective (Domain Knowledge): Research is conducted to understand how users capture, organize, and utilize information in real-world scenarios. This includes analyzing note-taking behaviors, the use of structured data for tracking and decision-making, and the challenges users face when interacting with multiple tools. Particular focus is placed on identifying inefficiencies in switching between note-taking, data management, and AI assistance. Gaining these insights is essential to ensure that the system design supports practical workflows, provides intuitive interaction methods, and effectively improves the overall knowledge management experience.
In-Scope Implementation
The Minimum Viable Product (MVP) for this thesis encompasses the following fully functional domains:
Core User Interface: A responsive, dark-mode desktop web application featuring an "Obsidian-Notion Hybrid" aesthetic, complete with a dual-sidebar navigation system and tab-based workspace.
Unstructured Data Management (Notes): A "Live Preview" WYSIWYG Markdown editor (powered by Milkdown) that supports core text formatting, real-time autosaving, and raw syntax toggling.
Structured Data Management (Stacks): A dynamic database table system allowing users to define custom schemas with strictly typed columns (Text, Integer, Float, Boolean, Date, Select) and basic column aggregations (Sum/Average).
The AI Microservice Pipeline: A standalone FastAPI backend executing a 4-stage pipeline: Audio Validation, Speech-to-Text (via Deepgram/Groq), Sentinel Security Classification, and Resolver NLU (via Gemini/Groq LLMs).
Voice-to-Action Execution: Push-to-talk functionality allowing users to dictate commands that map to specific actions: updating notes at the cursor position, creating new notes, managing tasks (create/update/delete), appending or updating rows in a Stack, and creating calendar events.
Human-in-the-Loop Confirmation UI: Visual staging areas for AI proposals, including inline red/green text diffs for Notes, yellow-highlighted "ghost rows" and bulk updates for Stacks, and popups for Tasks and Calendar events, coupled with Accept/Discard/Undo controls.
Conversational AI Interface: A sliding side-panel that displays natural-language AI replies for queries that do not require database mutations.
Authentication & Security: Google OAuth and Email/Password authentication via NextAuth.js, alongside per-request randomized UUID prompt injection defenses.
Out-of-Scope 
To maintain architectural focus on the core multimodal AI mechanics, the following features are explicitly excluded from this version of the system:
Mobile Applications: Native iOS or Android applications, as well as mobile-responsive CSS breakpoints, are excluded. The system is strictly optimized as a desktop-grade web application.
Always-On Listening: The AI relies on a deliberate "Push-to-Talk" trigger. "Wake-word" detection (e.g., "Hey Siri") is excluded due to privacy concerns and browser limitations.
Complex Database Relations: Advanced relational database features such as Stack-to-Stack joins, Rollups,.. are excluded. Stacks are limited to isolated, flat-table views.
AI Data Deletion & Modification: To prevent accidental data loss, major database alterations (such as deleting entire Stacks or modifying underlying tables' structural schemas) are excluded. The AI is restricted to editing individual rows, managing user tasks, and creating calendar entries safely under confirmation.
Real-Time Collaboration: Synchronous multi-user editing (e.g., Google Docs style collaborative cursors) is excluded. The system is designed as a Personal Knowledge Management (PKM) tool for individual users.
Offline Support: Local-first data caching and offline AI processing are excluded. The system requires an active internet connection to communicate with the Neon PostgreSQL database and cloud-based AI provider.
SCIENTIFIC AND PRACTICAL SIGNIFICANCE
Scientific significance
Explores the application of Multimodal Human-Computer Interaction (HCI) in Personal Knowledge Management (PKM): Investigates the effectiveness of voice-driven agentic AI in seamlessly manipulating both unstructured text (Markdown notes) and structured data (custom database tables), contributing to the evolution of intelligent, next-generation workspaces.
Develops a dynamic, schema-aware AI architecture: Establishes a strict, microservice-based model utilizing runtime schema generation (e.g., dynamic Pydantic models) to strictly constrain Large Language Model (LLM) outputs. This addresses critical challenges in mitigating AI hallucinations and enforcing deterministic data manipulation.
Demonstrates the "Human-in-the-Loop" safeguard paradigm: Provides a concrete case study on implementing a "Suggestion-Only" AI pipeline, complete with Sentinel-based prompt injection defenses and frontend confirmation gates. This proves that Agentic AI can safely propose workspace operations without compromising database integrity.
Serves as a foundation for future productivity technology research: Lays the groundwork for further studies into multi-model LLM routing (leveraging abstraction layers like LiteLLM) and ultra-low-latency voice-to-action pipelines within modern web-based ecosystems.
Practical significance


Optimizing information management workflows: Drastically reduces the friction of manual data entry by allowing users to update notes and structured tables simultaneously through natural language voice commands, bridging the gap between fleeting thoughts and recorded data.
Enhancing user productivity and focus: Minimizes context-switching for students and young professionals by integrating note-taking, structured data management, and AI assistance into a single unified interface, enabling them to maintain flow and focus on content creation rather than UI navigation.
Ensuring data safety and reliability: By forcing all AI actions through a user-confirmed gateway (visualized via inline text diffs and staging rows) and validating intents against strict database schemas, the system eliminates the risk of silent AI errors or accidental data corruption.
Lowering the technical barrier structured data management: Empowers non-technical users to populate and interact with complex structured tables (Stacks) using intuitive conversational commands, bypassing the traditional complexities of spreadsheet formulas or manual data formatting.
