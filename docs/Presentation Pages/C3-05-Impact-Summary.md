# C3-05 — Cross-Map: One Platform, Three Superpowers

## The One Big Idea
The same five modules. The same AI layer. Three completely different superpowers. Lock In doesn't force users into one workflow — the platform adapts. Each user scenario draws on a different combination of features, proving the system's flexibility.

## Visual Concept
A clean matrix grid: Features (rows) × Scenarios (columns). Each cell contains a checkmark and a one-word or short-phrase description of HOW that feature serves that user. Not a dense data table — a visual heat map. Cells with strong usage glow emerald. The pattern reveals that Notes serves all three, Stacks powers HR and Founder, Records transforms all three — but in different ways.

## Content Elements

### Feature × Scenario Matrix

| Feature | HR & Talent Lead | Academic Tutor | Founder & Business Owner |
|---|---|---|---|
| **Notes** | Interview notes, candidate summaries | Lesson plans, rubrics, teaching resources | Business ideas, meeting notes, strategy docs |
| **Stacks** | Candidate evaluation database ✦ | Minimal — grade tracking | Customer pipeline, growth experiments, partnerships ✦ |
| **Tasks** | Recruitment pipeline tracking ✦ | Homework assignments, administrative follow-ups | OKRs, milestones, action items |
| **Calendar** | Interview scheduling | Teaching sessions, consultations, deadlines | Investor meetings, product launches |
| **Records** | Interview recording + transcription ✦ | Speaking assessment upload + analysis ✦ | Voice capture on-the-go ✦ |
| **Agentic Automate** | Extract-to-Stack, candidate profiling ✦ | Lesson→task extraction | Thought→structured documentation ✦ |
| **AI Companion** | Candidate comparison queries | Grammar/vocab analysis ✦ | Conversational business intelligence ✦ |

✦ = Primary use for this scenario

### The Insight (bottom of slide)
The features don't change. The workflows do. One unified tool — adapted by AI to serve three completely different professionals.
