# C4-01 — AI Capabilities in Lock In

## The One Big Idea
Lock In's AI is not one thing — it is five integrated capabilities, each solving a specific trust or efficiency problem. Together, they form a complete agentic system that is fast, safe, and reliable.

## Visual Concept
Five equal-sized icon cards arranged in a horizontal row across the slide. Each card has a large Lucide icon at top, a capability name as the headline, and a single supporting sentence below. The cards are clean, identical in structure, letting the content differentiate them. The emerald accent appears only on the icon — subtle, consistent.

## Content Elements

### Headline
Five AI Capabilities. One Trusted System.

### Card 1 — Voice-to-Action
- **Icon**: Microphone
- **Headline**: Speak. Execute.
- **Supporting line**: Natural language voice commands in Vietnamese or English — AI maps intent directly to workspace operations. Notes, Stacks, Tasks, Calendar — all voice-controllable.

### Card 2 — Sentinel Security
- **Icon**: Shield
- **Headline**: Injection-Proof
- **Supporting line**: Cryptographic UUID delimiters wrap every transcript. A dedicated Llama-3.1-8B guard classifies and blocks prompt injection attacks before they reach core logic.

### Card 3 — Schema Enforcement
- **Icon**: Lock and key
- **Headline**: Zero Hallucinations
- **Supporting line**: Dynamic Pydantic models compile user-defined Stack schemas at runtime — mathematically forcing LLM output to match your column types. 100% type accuracy.

### Card 4 — Multi-Expert Reasoning
- **Icon**: Brain / network nodes
- **Headline**: Think Before Acting
- **Supporting line**: For complex commands, parallel expert agents — Contrarian, Research, Conversation, Planner — deliberate simultaneously before the Resolver generates a final action.

### Card 5 — Human-in-the-Loop
- **Icon**: User check / approve gesture
- **Headline**: You Always Decide
- **Supporting line**: Every AI proposal is staged visually — red/green text diffs for notes, yellow ghost rows for tables. Nothing writes to the database until you explicitly accept.
