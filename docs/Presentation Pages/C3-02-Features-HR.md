# C3-02 — Features for the HR & Talent Lead

## The One Big Idea
An HR lead managing candidate pipelines moves from scattered CVs, disconnected interview notes, and manual spreadsheet updates — to a structured, AI-powered recruitment command center where candidate data is extracted, scored, and compared automatically.

## Visual Concept
A "Before → After" horizontal transformation. Left side: chaotic — scattered icons (PDF, notepad, spreadsheet) with a frustrated face emoji. Right side: structured — a clean workflow showing the Lock In modules in sequence (Stacks → Records → Agentic Automate → Tasks → AI Companion) with checkmarks. The contrast is stark and emotional.

## Content Elements

### Headline
From Scattered CVs to Structured Candidate Intelligence

### The Pain (Before)
Candidate data lives in PDFs. Interview feedback in scattered notes. Hiring progress tracked in separate spreadsheets. Moving information between systems is the full-time job.

### The Lock In Workflow (After)

| Step | Module | What Happens |
|---|---|---|
| 1 | **Stacks** | Build a candidate evaluation database — columns: Name, Position, Experience, Skills, Interview Score, Recommendation |
| 2 | **Records** | Upload interview recordings — automatic transcription into searchable text |
| 3 | **Agentic Automate** | AI extracts candidate strengths, weaknesses, and scores — populates Stack rows as ghost rows for review |
| 4 | **Tasks** | Track recruitment pipeline: CV screening → Interview scheduling → Offer preparation → Onboarding |
| 5 | **AI Companion** | "Compare candidates for the Senior Developer role" — AI queries your Stack data and responds conversationally |

### Key Expectations Delivered
Bulk data extraction into structured tables ✓ AI-powered candidate profiling and scoring ✓ Extract-to-Stack automation ✓ Pipeline task tracking ✓
