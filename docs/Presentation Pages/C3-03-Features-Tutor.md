# C3-03 — Features for the Academic Tutor

## The One Big Idea
An academic tutor transforms from manually reviewing hours of student recordings, hunting through folders for lesson materials, and juggling disconnected schedules — to an AI-assisted instructional system where speaking assessments are analyzed automatically and lesson plans convert to tasks with one command.

## Visual Concept
A "Before → After" horizontal transformation. Left side: scattered — stacks of papers, audio files, a wall calendar — overwhelming. Right side: structured workflow — Notes (lesson hub) → Records (assessment upload) → AI Companion (grammar/vocab analysis) → Agentic Automate (lesson→task extraction) → Calendar (weekly planning). Clean, organized, empowering.

## Content Elements

### Headline
From Hours of Manual Review to AI-Assisted Instruction

### The Pain (Before)
Lesson plans in scattered folders. Student speaking recordings reviewed manually — each one played start to finish. Schedules across multiple calendars. Assessment feedback inconsistent and time-consuming.

### The Lock In Workflow (After)

| Step | Module | What Happens |
|---|---|---|
| 1 | **Notes** | Central knowledge hub — lesson plans, teaching resources, assessment rubrics, revision materials, all organized in one place |
| 2 | **Records** | Upload student speaking assessments — automatic transcription alongside original audio |
| 3 | **AI Companion** | AI analyzes transcripts for grammar mistakes, vocabulary misuse, awkward sentence structures, and areas for improvement |
| 4 | **Agentic Automate** | Extract homework assignments, revision activities, mock tests from finalized lesson plans — convert to Tasks automatically |
| 5 | **Calendar** | Weekly planning: teaching sessions, student consultations, assessment deadlines — all visible at a glance |

### Key Expectations Delivered
AI-powered assessment analysis ✓ Inline transcript insights ✓ Automatic task extraction from lessons ✓ Central calendar for all activities ✓
