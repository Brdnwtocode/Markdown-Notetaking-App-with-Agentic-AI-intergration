# C1-03 — What Is Lock In

## The One Big Idea
Lock In is a full-stack web workspace that combines Markdown notes, structured database tables (Stacks), task management, a calendar, and an audio workstation — all wrapped around an AI voice companion that understands your context and proposes changes you approve.
